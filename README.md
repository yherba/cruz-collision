# Cruz Brothers Collision

A one-page draft website for Cruz Brothers Collision, an auto body and paint shop in Leon Valley, TX.

- Plain HTML and CSS in `index.html`, with no build step. Photos are in `images/`.
- Has an English/Spanish toggle. The English text is in the HTML, and the Spanish text is in the `ES` object near the bottom of `index.html`.
- Things still waiting on the owner are tagged `class="tbd"`. See [QUESTIONS.md](QUESTIONS.md) for the list.
- Hosted on GitHub Pages from the `main` branch.
